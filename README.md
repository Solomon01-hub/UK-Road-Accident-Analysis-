# UK Road Accidents Analysis

Exploratory analysis, Association rule mining, regional clustering, and 
time series forecasting on UK road accident data.

## Questions I'm exploring
- Does accident severity correlate with lighting or weather conditions?
- Which combinations of factors (road type, junction, surface, time) show up together in severe accidents?
- Which regions have the worst accident profiles, and what do they have in common?
- Is there a seasonal or monthly pattern in accident frequency?

## Dataset
UK Department for Transport Road Safety Data (Kaggle mirror).
(https://www.kaggle.com/datasets/atharvasoundankar/road-accidents-dataset?resource=download)

## Approach
1. Data cleaning and preprocessing
2. Exploratory data analysis (temporal, severity, conditions)
3. Association rule mining (Apriori) on contributing factors
4. Regional clustering (K-means)
5. Time series forecasting of accident trends

## Tools
Python, pandas, scikit-learn, mlxtend, matplotlib/seaborn, Jupyter
